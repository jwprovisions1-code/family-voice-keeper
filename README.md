# family-voice-keeper
Small private web app: a keepsake page with an embedded 3D hologram, push-to-talk speech
recognition (browser), a persona chat endpoint (Gemini), and voice replies (ElevenLabs).
All secrets live in environment variables; nothing personal is in this repo.

Run: `npm install && npm start`
Env: ELEVENLABS_API_KEY, ELEVENLABS_VOICE_ID, GEMINI_API_KEY, GEMINI_MODEL, PERSONA_PROMPT, PAGE_PATH
